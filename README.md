# DC Motor Speed Control Using MOSFET

A simple and low-cost analog electronics mini-project designed to control the rotational speed of a DC motor using an IRFZ44N N-channel MOSFET and a 10 kΩ potentiometer.

The potentiometer is used to vary the MOSFET gate voltage, controlling the current supplied to the DC motor and thereby changing its speed. The circuit is implemented on a breadboard using a 9V DC power supply.

**Components Used:**
- IRFZ44N N-Channel MOSFET
- 10 kΩ Potentiometer
- 9V DC Battery
- DC Motor
- Breadboard and Connecting Wires

**Key Features:**
- Adjustable DC motor speed
- Simple analog circuit design
- Low-cost and easily available components
- Breadboard-based hardware implementation
- Demonstrates MOSFET switching and motor control

**Technologies:** Analog Electronics, MOSFET, Electronic Switching, DC Motor Control.

**Project Type:** Analog Electronics Mini Project
